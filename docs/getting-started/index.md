# Erste Schritte

Ein typischer Ablauf besteht aus vier Schritten:

1. Führe die [Ersteinrichtung](/guide/setup) aus und lege Währung sowie Strompreis fest.
2. Erfasse [Drucker, Komponenten, Filamente und optional Kunden](/guide/master-data).
3. Erstelle einen [Druckentwurf mit Live-Kostenaufschlüsselung](/guide/print-workflow).
4. Schließe den Druck ab. Der gespeicherte Snapshot bleibt unverändert, auch wenn sich Stammdatenpreise ändern.

![Ablauf von Stammdaten über Entwurf und Abschluss-Snapshot bis zum Duplikat](/print-workflow.svg)

Für eine produktive Installation beginnt der Weg im [Deployment-Runbook](/operations/deployment).
