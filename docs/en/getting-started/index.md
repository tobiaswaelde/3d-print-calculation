# Getting started

A typical journey has four steps:

1. Complete [first-run setup](/en/guide/setup) and select currency and electricity price.
2. Add [printers, components, filaments, and optional customers](/en/guide/master-data).
3. Create a [print draft with a live cost breakdown](/en/guide/print-workflow).
4. Complete the print. Its snapshot remains unchanged when master-data prices change later.

![Flow from master data through draft and completed snapshot to a duplicate](/print-workflow.svg)

For production installation, begin with the [deployment runbook](/en/operations/deployment).
